# BeatSaver-BookmarkChanger

## なんやこれ

ブックマークボタンを押してブックマークに入れると、そのマップカードに背景画像が設定されるようになります  
もう一度押してオフにすると、背景画像が削除され、もとに戻ります  
  
配信外でブックマークを押しておいて配信でそのマップをリクエストしたい、などのケースを想定してつくりました

## 使い方

Tampermonkey で新しいスクリプトを作成し、コードを貼り付けてください  
マップのページでは動作しません。マッパーのページとカタログ一覧のページでのみ動作します

## 既知の問題

たまに動かないことがあるのでそのときはページをリロードするか、ページ移動で直ると思います
